## 项目简介

Frame Vault 面向需要在本机集中管理创作素材的用户。素材导入后会保存在当前浏览器的本地数据库中，不需要注册账号，也不会主动上传到远程服务器。

平台能够自动读取素材的格式、文件大小、分辨率、画面比例、方向和时长等信息，并支持自定义类目、跨类目搜索、右侧快速预览以及整库备份与恢复。

## 主要功能

- 图片、视频、音频和文本四种独立素材入口。
- 自动识别格式、文件大小、图片或视频分辨率、画面比例、方向和媒体时长。
- 全部素材、图片、视频、音频、文本以及自定义类目独立筛选。
- 可添加、删除自定义类目，并可把当前素材移动到任意类目或素材库根目录。
- “全部素材”搜索可以同时搜索素材库根目录和所有自定义类目中的内容。
- 图片支持右侧预览、`Ctrl + 鼠标滚轮` 缩放，放大后可按住鼠标拖动画面。
- 视频默认暂停，支持原生播放控制和下载。
- 音频支持试听、时长识别和下载。
- 文本支持本机编辑、自动保存、复制、下载和沉浸式阅读。
- 图片和视频素材可单独记录生成提示词；文本和音频不显示提示词框。
- 素材、类目和个人提示词状态保存在本机，刷新页面后仍然保留。
- 支持导出一个 `.framevault` 整库备份文件，并在另一台电脑上一键恢复。
- 恢复时可选择“安全合并”或“完全恢复”。
- 自适应浏览器可用高度，Windows 任务栏显示或隐藏时左栏仍可正常滚动。

## 支持的素材格式

| 类型 | 可识别扩展名 |
| --- | --- |
| 图片 | JPG、JPEG、PNG、WebP、GIF、BMP、AVIF、HEIC、HEIF |
| 视频 | MP4、MOV、M4V、WebM、AVI、MKV、MPEG、MPG |
| 音频 | MP3、WAV、M4A、AAC、OGG、FLAC、OPUS、WMA |
| 文本 | TXT、MD、Markdown |

> 能够导入和识别扩展名，不代表浏览器一定能够直接解码播放。例如部分 MOV、MKV、AVI、HEIC 或专有编码文件可能只能保存和下载，预览能力取决于当前浏览器及系统解码器。

## 本地部署

### 环境要求

- Windows、macOS 或 Linux。
- [Node.js](https://nodejs.org/) `22.13.0` 或更高版本。
- npm（随 Node.js 安装）。
- 推荐使用最新版 Chrome、Edge 或其他 Chromium 浏览器。

### 安装与启动

```bash
git clone https://github.com/zhouchunyu67-ai/zhouchunyu.git
cd zhouchunyu
npm install
npm run dev
```

看到本地地址后，在浏览器打开：

```text
http://localhost:3000/
```

保持运行命令的终端窗口开启。停止平台时，在终端按 `Ctrl + C`。

### 让 Codex 协助部署

在另一台已安装 Git、Node.js 和 Codex 的电脑上，可以把下面这段话直接交给 Codex：

```text
请克隆 https://github.com/zhouchunyu67-ai/zhouchunyu.git，安装依赖，运行测试并在本机启动 Frame Vault。不要把本机素材或 .framevault 备份文件提交到 Git。
```

## 在另一台电脑恢复现有素材

1. 在旧电脑打开 Frame Vault。
2. 点击左下角“本机持久保存”展开状态区。
3. 点击“整库备份”，下载 `.framevault` 文件。
4. 在新电脑完成项目部署，并打开相同的本地地址。
5. 展开“本机持久保存”，点击“恢复素材库”。
6. 选择或拖入旧电脑导出的 `.framevault` 文件。
7. 选择恢复方式并确认：
   - **安全合并**：保留新电脑已有内容，只补充备份中的其他记录。
   - **完全恢复**：清空当前本地素材库，再完整写入备份内容。

建议把 `.framevault` 文件保存在个人硬盘或可信的私人存储中。备份文件可能包含全部原始素材和文本内容，不适合公开上传。

## 数据保存与隐私

- 素材和设置使用浏览器的 IndexedDB 保存在当前设备。
- 平台不会主动把素材上传至 GitHub 或其他远程服务。
- 同一台电脑上的不同浏览器、不同浏览器用户配置或不同端口会使用相互独立的本地数据空间。
- 清理浏览器网站数据、重置浏览器配置或卸载浏览器，可能同时删除本地素材库。
- 更换电脑或清理浏览器前，请先导出 `.framevault` 整库备份。
- Git 已忽略常见图片、视频、音频、本地素材目录和 `.framevault` 文件，避免误把私人素材提交到仓库。

```text

  page.tsx          主界面与素材交互
```

## 使用提示

- 第一次进入时素材库为空，需要手动导入素材或恢复备份。
- 导入大量高清视频前，请确认磁盘剩余空间充足。
- 素材卡片缩略图和媒体参数可能需要短暂读取时间。
- 视频打开大预览后仍保持默认暂停，不会自动播放声音。
- 桌面快捷方式和 `start-media-desk.ps1` 可能包含创建者电脑上的本地路径。其他电脑建议先使用标准的 `npm run dev` 启动；如需快捷方式，应根据实际安装目录重新生成。
