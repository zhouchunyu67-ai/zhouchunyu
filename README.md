## 项目简介

Frame Vault 面向需要在本机集中管理创作素材的个人创作者和小型工作流。默认情况下，素材导入后会保存在当前浏览器的 IndexedDB 中；也可以选择硬盘、移动硬盘或 U 盘中的文件夹作为外部素材目录。平台不需要注册账号，普通素材管理不会主动上传到远程服务器。

平台能够自动读取素材的格式、文件大小、分辨率、画面比例、方向和时长等信息，并支持自定义类目、跨类目搜索、右侧快速预览、New.bi AI 生成、普通整库备份以及带密码的加密跨电脑迁移。

项目分为两个边界：素材库和提示词默认留在浏览器或用户授权的外部目录中；AI 生成请求才会经由本地 Worker 代理发送到 New.bi。New.bi API Key 只在服务端环境变量中使用，浏览器不会读取密钥。

## 主要功能

- 图片、视频、音频、文本和链接五种独立素材入口。
- 自动识别格式、文件大小、图片或视频分辨率、画面比例、方向和媒体时长。
- 全部素材、图片、视频、音频、文本、链接以及自定义类目独立筛选。
- 可添加、删除自定义类目，并可把当前素材移动到任意类目或素材库根目录。
- “全部素材”搜索可以同时搜索素材库根目录和所有自定义类目中的内容。
- 图片支持右侧预览、`Ctrl + 鼠标滚轮` 缩放，放大后可按住鼠标拖动画面。
- 视频默认暂停，支持原生播放控制和下载。
- 音频支持试听、时长识别和下载。
- 文本支持本机编辑、自动保存、复制、下载和沉浸式阅读。
- 链接支持自定义名称、网址跳转和本机自动保存的描述信息。
- 图片和视频素材可单独记录生成提示词；文本和音频不显示提示词框。
- 素材、类目和个人提示词状态保存在本机，刷新页面后仍然保留。
- 内置独立的 New.bi AI 生成工作台，支持 GPT Image 2、Seedream 5.0、MiniMax H3、PixVerse Mimic、Seedance 2.0 和 Seedance 2.5。
- 支持从本地素材库或电脑添加图片、视频和音频参考，并在提示词中使用 `@` 引用已添加的素材。
- AI 生成结果可以自动下载并写回本机素材库；服务端模型白名单和公网访问口令用于降低误调用风险。
- 支持 `.framevault` 普通整库备份与恢复，包含素材文件、分类、素材提示词、收藏、最近使用和草稿状态。
- 支持 `.framevault-migration` 加密迁移包，使用 PBKDF2-SHA-256 和 AES-256-GCM 保护 `.dev.vars` 与素材库；大型备份按 16 MB 分块加密，超过 1.5 GB 时建议改用外部目录迁移。
- 支持外部硬盘、移动硬盘和 U 盘目录同步；外部目录会保存素材文件和索引，换电脑后需要重新选择并授权目录。
- 可选择硬盘、移动硬盘或 U 盘目录，同步保存源文件、文本内容、类目和提示词索引。
- 外部目录断开或权限失效时会显示异常状态，重新连接后可继续同步。
- 停止使用外部目录不会删除其中的文件，浏览器本地副本继续保留，可随时回退。
- 支持导出一个 `.framevault` 整库备份文件，并在另一台电脑上一键恢复。
- 恢复时可选择“安全合并”或“完全恢复”。
- 自适应浏览器可用高度，Windows 任务栏显示或隐藏时左栏仍可正常滚动。

## 支持的素材格式

| 类型 | 可识别扩展名 |
| --- | --- |
| 图片 | JPG、JPEG、PNG、WebP、GIF、BMP、AVIF、HEIC、HEIF |
| 视频 | MP4、MOV、M4V、WebM、AVI、MKV、MPEG、MPG |
| 音频 | MP3、WAV、M4A、AAC、OGG、FLAC、OPUS、WMA |
| 文本 | TXT、MD、Markdown |
| 链接 | HTTP、HTTPS 网页地址 |

> 能够导入和识别扩展名，不代表浏览器一定能够直接解码播放。例如部分 MOV、MKV、AVI、HEIC 或专有编码文件可能只能保存和下载，预览能力取决于当前浏览器及系统解码器。

## 本地部署

### 环境要求

- Windows、macOS 或 Linux。
- [Node.js](https://nodejs.org/) `22.13.0` 或更高版本。
- npm（随 Node.js 安装）。
- 推荐使用最新版 Chrome、Edge 或其他 Chromium 浏览器。

### 安装与启动

```bash
git clone https://github.com/zhouchunyu67-ai/zhouchunyu.git
cd zhouchunyu
npm install
npm run dev
```

看到本地地址后，在浏览器打开：

```text
http://localhost:3000/
```

保持运行命令的终端窗口开启。停止平台时，在终端按 `Ctrl + C`。

### 接入 New.bi AI 生成

工作台现已内置六个受控模型入口，并通过独立的本地 `/ai` 页面使用：

| 工作台名称 | New.bi 模型名 | 用途 | 密钥分组 |
| --- | --- | --- | --- |
| GPT Image 2 | `gpt-image-2-d` | 图片生成与多图编辑 | New.bi-gpt-image-2 |
| Seedream 5.0 | `doubao-seedream-5-0-260128` | 图片生成 | 支持该模型的 New.bi 图片分组 |
| MiniMax H3 | `minimax-h3-768p` | 文本/图片/音频参考的视频生成 | New.bi 视频组 |
| PixVerse Mimic | `pixverse-mimic` | 参考视频动作迁移到目标人物图片 | New.bi 视频组 |
| Seedance 2.0 | `doubao-seedance-2-0-260128` | 视频生成 | New.bi 视频组 |
| Seedance 2.5 | `sd-2-5` | 720P 多模态视频生成 | New.bi 视频组 |

推荐在 New.bi 分别创建一把图片组密钥和一把视频组密钥。项目使用服务端 Worker 代理调用：浏览器只请求本项目的 `/api/ai/*`，不会读取或收到 New.bi API Key。

本机配置步骤：

1. 在 New.bi 密钥页创建所需分组的密钥。
2. 复制 `.dev.vars.example` 为 `.dev.vars`。
3. 只在本机的 `.dev.vars` 中填入真实密钥；不要修改或提交示例文件中的占位值。
4. 重新启动 `npm run dev`，点击素材库顶部的“AI 生成”进入独立生成页面。
5. 生成成功后，图片或视频会自动下载并保存进浏览器本地素材库。

```powershell
Copy-Item .dev.vars.example .dev.vars
npm run dev
```

`.dev.vars`、`.dev.vars.*` 和 `.env*` 已加入 Git 忽略规则，仓库只保留无密钥的示例。其他人克隆仓库后必须自己创建配置文件并填入自己的密钥。

如果部署到公网，还必须设置 `MEDIA_DESK_AI_ACCESS_TOKEN`。这是给工作台使用者输入的独立访问口令，不是 New.bi API Key；未设置时，公网环境的 AI 代理会默认关闭，避免公开站点被陌生人消耗额度。所有线上变量都应通过托管平台的 Secret / Environment Variables 面板设置，不要写进源码。

#### 加密迁移包

如果要把素材库和本机 AI 配置一起迁移到另一台电脑，可在素材库左下角打开持久化区域，选择“加密迁移包”。导出时粘贴当前 `.dev.vars` 内容并设置至少 8 位迁移密码；浏览器会在本机使用 PBKDF2-SHA-256 和 AES-256-GCM 加密素材、提示词和配置，生成 `.framevault-migration` 文件。大型素材备份按 16 MB 分块加密以降低浏览器内存峰值；素材总量超过 1.5 GB 时建议改用外部硬盘目录迁移。迁移密码不会保存，也无法找回。

在新电脑完成项目安装后，打开同一页面选择“导入迁移包”，输入迁移密码并选择文件。系统会安全合并素材库；点击恢复时会优先让你选择新电脑的项目根目录，并直接写入其中的 `.dev.vars`，然后重启 `npm run dev` 让 Worker 重新读取 API Key。如果浏览器不支持目录写入或你取消了目录选择，系统才会下载 `.dev.vars`，请手动将其放回项目根目录后重启开发服务。加密迁移包不是普通 `.framevault` 备份，不能互相替代；外部硬盘/U 盘目录仍需在新电脑重新选择并授权。不要把迁移密码和文件放在同一位置，也不要把未加密的 `.dev.vars` 提交到 Git。

当前适配器支持纯文本生成、参考素材和生成结果自动入库。先从本机素材库或电脑添加参考素材；之后在提示词中输入 `@`，只会列出已添加的素材，并以 `@图片1`、`@视频1` 或 `@音频1` 标签插入到光标位置。GPT Image 2 和 Seedream 接受参考图片，MiniMax H3 接受文本、图片、视频与音频参考；PixVerse Mimic 使用一张人物图片和一段动作视频完成动作迁移；Seedance 2.0 接受图片、视频与音频，Seedance 2.5 接受图片和音频参考。参考文件只会在用户点击生成时发送到所选模型。

GPT Image 2 提供 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9` 八种画幅，并由服务端映射为实际像素尺寸。视频时长按模型的完整整数秒范围列出：MiniMax H3、PixVerse Mimic 为 5–15 秒，Seedance 2.0 为 4–15 秒，Seedance 2.5 为 4–30 秒。由于 New.bi 的新模型接口仍可能调整，六个模型名均可用 `.dev.vars` 中的可选变量覆盖；首次充值调用前建议先用低成本参数各做一次验收。

## 在另一台电脑恢复现有素材

1. 在旧电脑打开 Frame Vault。
2. 点击左下角“本机持久保存”展开状态区。
3. 点击“整库备份”，下载 `.framevault` 文件。
4. 在新电脑完成项目部署，并打开相同的本地地址。
5. 展开“本机持久保存”，点击“恢复素材库”。
6. 选择或拖入旧电脑导出的 `.framevault` 文件。
7. 选择恢复方式并确认：
   - **安全合并**：保留新电脑已有内容，只补充备份中的其他记录。
   - **完全恢复**：清空当前本地素材库，再完整写入备份内容。

建议把 `.framevault` 文件保存在个人硬盘或可信的私人存储中。备份文件可能包含全部原始素材和文本内容，不适合公开上传。

## 使用硬盘或 U 盘素材目录

1. 点击左下角“本机持久保存”展开状态区。
2. 点击“选择硬盘 / U盘目录”。
3. 选择一个空文件夹，或者之前由 Frame Vault 创建的素材目录。
4. 允许浏览器读取和写入该目录。
5. 如果目录为空，平台会先复制并校验当前素材，再启用同步。
6. 如果目录已有 `frame-vault-library.json`，平台会读取其中的素材并安全合并到当前本地库。

外部目录中包含：

```text
选择的素材目录/
  media/
    image/
    video/
    audio/
    text/
    link/
  frame-vault-library.json
  README-请勿手动修改.txt
```

素材的新增、删除、名称、类目、文本内容、链接地址、链接描述和图片/视频提示词会自动同步。媒体源文件和链接快捷方式使用稳定编号保存，显示名称和类目记录在索引文件中，因此更改类目时不需要移动大型视频。

平台仍会保留浏览器本地副本作为回退保护。点击“停止使用”只关闭后续同步，不会删除外部目录或浏览器副本。U 盘或移动硬盘断开时，顶部会显示目录离线状态；重新插入后展开状态区并点击“重新连接”。

## 数据保存与隐私

- 默认模式下，素材和设置使用浏览器的 IndexedDB 保存在当前设备。
- 启用外部目录后，源文件与 `frame-vault-library.json` 会同步到用户授权的文件夹，同时保留 IndexedDB 副本以便回退。
- 不要让两台电脑同时写入同一个外部素材目录；换电脑前请等待同步完成并安全弹出硬盘或 U 盘。重新连接时，如果外部目录来自另一台电脑且版本更新，会把外部内容安全合并到当前素材库。
- 平台不会主动把素材上传至 GitHub 或其他远程服务。
- 同一台电脑上的不同浏览器、不同浏览器用户配置或不同端口会使用相互独立的本地数据空间。
- 清理浏览器网站数据、重置浏览器配置或卸载浏览器，可能同时删除本地素材库。
- 更换电脑或清理浏览器前，请先导出 `.framevault` 整库备份。
- Git 已忽略常见图片、视频、音频、本地素材目录和 `.framevault` 文件，避免误把私人素材提交到仓库。

## 功能边界与安全说明

- 普通素材管理、预览、分类和备份都在本机完成；是否访问外部目录由用户逐次授权。
- AI 生成只会在用户点击生成后发送请求和已选择的参考素材，New.bi API Key 不会发送到浏览器。
- `.dev.vars`、`.dev.vars.*`、`.env*`、媒体文件、`.framevault` 和 `.framevault-migration` 均不应提交到 Git。
- 加密迁移包的密码不会保存，也无法找回；迁移包和密码应分开保存。
- 外部目录授权属于浏览器权限，迁移到另一台电脑后必须重新选择并授权。
- 项目默认使用浏览器本地存储，清理站点数据或重置浏览器可能删除本机素材副本；进行系统迁移前请先完成备份。

## 项目结构

```text
app/
  page.tsx          主界面与素材交互
  ai.ts             AI 生成客户端与结果导入
  ai/page.tsx       独立 AI 生成工作台
  globals.css       二次元主题和响应式布局
  storage.ts        浏览器本地数据库读写
  backup.ts         .framevault 备份和恢复
  migration.ts      加密迁移包的创建、解密和校验
  externalStorage.ts 硬盘与 U 盘素材目录同步

tests/              页面、持久化、备份、AI 和迁移测试
worker/
  index.ts          本地和构建运行入口
  newbi.ts          New.bi 服务端代理、模型白名单与结果下载
```

## 使用提示

- 第一次进入时素材库为空，需要手动导入素材或恢复备份。
- 导入大量高清视频前，请确认磁盘剩余空间充足。
- 素材卡片缩略图和媒体参数可能需要短暂读取时间。
- 视频打开大预览后仍保持默认暂停，不会自动播放声音。
- 外部目录功能推荐使用最新版 Chrome 或 Edge；浏览器可能在重新启动后要求再次授权。
- 使用 U 盘或移动硬盘时，请等待同步完成后再安全弹出设备。
- 桌面快捷方式和 `start-media-desk.ps1` 可能包含创建者电脑上的本地路径。其他电脑建议先使用标准的 `npm run dev` 启动；如需快捷方式，应根据实际安装目录重新生成。
